# 캐릭터 스프라이트

모든 캐릭터는 상하좌우 방향의 대기 애니메이션과 이동 애니메이션을 준비합니다.

| 파일 | 내용 |
|---|---|
| protagonist-idle-v1.png | 주인공의 호흡 대기 루프 시안 |
| watcher-idle-v1.png | Watcher의 미세한 움직임을 포함한 대기 루프 시안 |
| protagonist-v1.png | 기존 주인공 이동 시트 |
| watcher-v1.png | 기존 Watcher 이동 시트 |

대기 시트는 4행 × 4열로 구성합니다.
위에서부터 아래·왼쪽·오른쪽·위 방향이며, 각 행의 4프레임을 왼쪽에서 오른쪽으로 반복 재생합니다.
대기에서는 발을 고정하고 상체와 팔에 미세한 움직임을 줍니다.
Watcher가 관측되면 애니메이션도 현재 프레임에서 멈추도록 구현합니다.

기존 이동 시트는 동일한 방향 순서입니다.
첫 열은 정지 기준 자세이며, 이동 루프는 2·3·4·3열 순서로 재생하는 초기 구성입니다.

새 대기 PNG는 각각 1254 × 1254px입니다.
4등분 경계는 0, 314, 627, 940, 1254px로 반올림해 사용할 수 있습니다.
게임 적용 전 프레임별 기준점 정렬과 루프 재생을 확인해야 합니다.
현재 PNG의 투명도와 크기를 확인했으며, 새 대기 애니메이션은 게임에 연결하기 전 단계입니다.
