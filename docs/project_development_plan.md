# OUT OF SIGHT 프로젝트 개발 계획

## 프로젝트 목표

OUT OF SIGHT는 Python과 Pico2D로 만드는 2D 쯔꾸르 스타일의 공포 퍼즐 게임입니다. 주인공은 연락이 끊긴 동생을 찾으러 별장에 들어갑니다. 플레이어는 Watcher를 바라봐 움직임을 멈추고, 시선을 돌려 원하는 위치로 유도합니다. 첫 번째 퍼즐은 이 규칙으로 압력 발판을 눌러 문을 여는 것입니다.

현재 목표는 **새 게임 → 오프닝 → 1층 발판 퍼즐 → 귀빈실 → 2층 갤러리**까지 자연스럽게 이어지는 플레이를 완성하고 검증하는 것입니다.

## 작업 경로와 실행

- 실제 작업 폴더는 `OneDrive\문서\Git_Hub\2DGP-2025180028\OutOfSight`입니다.
- Python 3.10 이상과 `requirements.txt`에 지정된 Pico2D를 사용합니다.
- 프로젝트 루트에서 아래 명령을 실행합니다.

```powershell
python -m pip install -r requirements.txt
python game/main.py
```

| 위치 | 역할 |
| --- | --- |
| `game/main.py`, `game/framework.py` | 실행 진입점, 화면 상태와 입력, 게임 루프 |
| `game/opening.py`, `game/dialogue.py` | 오프닝 진행, 대본 읽기와 글자 출력 |
| `game/first_puzzle.py`, `game/navigation.py` | 맵 충돌, 출입구, Watcher, 경로 탐색과 첫 퍼즐 |
| `game/view.py`, `game/lighting.py` | 화면 그리기, 캐릭터 애니메이션과 조명 |
| `game/persistence.py`, `game/saves/` | 저장·복원 코드와 실행 중 생성되는 저장 데이터 |
| `game/art/`, `assets/sprites/` | 맵·UI·오프닝 에셋과 캐릭터 스프라이트 |
| `story/`, `docs/` | 스토리·대본, 개발 명세, 층별 구조도와 발표 자료 |
| `src/` | 초기 이동 프로토타입 코드 |

## 현재 구현 상태

아래는 코드와 에셋에서 확인한 기능입니다. 전체 흐름의 실제 화면 검증은 다음 작업에 포함합니다.

| 영역 | 현재 상태 |
| --- | --- |
| 타이틀과 조작 | 새 게임, 이어하기, 설정, 인벤토리, 일시 정지 메뉴가 있습니다. WASD로 이동하고, Space+WASD로 제자리에서 방향을 바꾸며, E로 조사하고 F로 손전등을 전환합니다. |
| 오프닝 | 집과 자동차 장면에서 시작해 별장 앞부터 직접 움직입니다. 초인종과 창문을 조사한 뒤 복도에서 동생의 휴대전화를 줍습니다. 전화 연결음, 음성사서함, 천둥과 정전 연출이 들어가 있습니다. |
| 대화와 조명 | 쯔꾸르식 대화창은 대사를 한 글자씩 표시합니다. 출력 중 Space는 대사를 완성하고, 완료 후 Space는 다음 대사로 넘깁니다. 대화 중 게임 진행은 멈추며 정전 이후에는 전방 시야와 벽 가림을 적용합니다. |
| 저택 | 1층은 현관·접객 홀·서비스 복도의 공용 맵과 식당·주방·욕실·귀빈실로 구성됩니다. 귀빈실 계단으로 2층 갤러리를 왕복할 수 있습니다. 2층 전용 퍼즐과 아이템은 아직 없습니다. |
| Watcher와 첫 퍼즐 | 1층에 Watcher 3마리를 배치했습니다. 첫 Watcher는 식당 옷장을 열면 활성화되고 관측되면 정지합니다. 나머지는 첫 퍼즐을 해결한 뒤 초기 배치 방에 입장하면 활성화됩니다. 관측 밖에서는 A*로 추적하거나 배회하고, 통과 가능한 출입구를 이용합니다. 플레이어와 활성화된 Watcher가 발판을 밟으면 귀빈실 문이 열립니다. 귀빈실에서는 방문 기록부를, 선택 동선에서는 열쇠로 열린 욕실의 탐색 단서를 얻을 수 있습니다. |
| 실패와 저장 | Watcher와 접촉하면 게임 오버 화면으로 전환합니다. 저장 슬롯은 3개이며, 수동 저장과 이어하기를 지원합니다. 실제 플레이 시간 60초마다 현재 슬롯에 자동 저장하는 구현이 있습니다. |

## 다음 개발 순서

| 순서 | 작업 | 완료 기준 |
| --- | --- | --- |
| 1 | 오프닝부터 2층까지 한 번에 플레이 | 새 게임으로 시작해 별장 도착, 휴대전화, 정전, 발판, 기록부, 2층 왕복을 실제 입력으로 진행할 수 있습니다. 전화 연결음과 음성사서함 순서, 대사 말투와 출력, 번쩍임·흔들림·어둠 전환을 확인합니다. |
| 2 | 1층 동선과 첫 퍼즐 조정 | 벽과 통로의 그림이 실제 충돌과 일치합니다. 문과 발판의 관계를 조사로 파악하고, 실패 후 Watcher를 다시 유도할 수 있습니다. 방 사이 이동과 다른 Watcher의 개입이 퍼즐을 막지 않는지 확인합니다. |
| 3 | 게임 오버와 저장 흐름 검증 | 접촉 시 게임 오버로 전환하고 마지막 저장 지점으로 돌아올 수 있습니다. 슬롯 간 저장 데이터가 섞이지 않으며, 일시 정지·대화·실패 상태에서 자동 저장으로 정상 진행을 덮지 않습니다. 재실행 후 현재 방, 아이템, Watcher 상태가 복원되는지 확인합니다. |
| 4 | 2층의 목표와 기믹 설계 | 2층에 올라가는 이유, 해결할 기믹, 완료 후 연결할 장소를 정합니다. 배치도와 완료 기준을 작성한 다음 작은 프로토타입으로 검증합니다. |
| 5 | 이후 스테이지와 몬스터 확장 | 핵심 플레이를 검증한 뒤 Shade·Breaker, 추가 퍼즐, 탈출 조건과 공포 연출을 단계별로 설계합니다. |

2층 기믹과 추가 몬스터의 능력은 이후 기획 항목입니다. 당장 조정할 후보는 첫 퍼즐의 단서, 벽과 통로 가독성, Watcher 유도 난이도입니다.
