# OUT OF SIGHT 오프닝 개발 명세서

타이틀의 **새 게임**을 선택하면 동생의 연락이 끊긴 이유를 확인하러 별장에 가는 오프닝이 시작됩니다. 집과 자동차 장면은 대화로 진행합니다. 별장 앞에 도착하면 플레이어가 직접 탐색하고, 정전 장면의 대화가 끝나면 별장 1층 탐색을 이어갑니다.

- [오프닝 대사 스크립트](../story/opening_stroy_script.md)

## 장면 구성과 이미지 제작

대본의 대사 순서를 따릅니다. 별장에 도착하면 외부 배경을 이동과 충돌 판정이 있는 탐색 맵으로 사용합니다. 별장 구간은 대사 흐름에 맞춰 외관, 창문, 복도, 정전으로 나눕니다.

| 장면 | 제작하거나 준비할 이미지 | 화면 전환 시점 |
| --- | --- | --- |
| 주인공의 집 | 오후의 실내 배경, 동생이 위치를 보낸 휴대전화 문자 화면 | 오프닝 시작. 문자부터 출력합니다. |
| 자동차 안 | 차 내부에서 바라본 이동 장면 | 주인공이 별장에 가기로 한 뒤 첫 음성사서함 대사로 넘어갈 때 |
| 별장 입구 | 현관등이 켜진 별장 외관과 현관 앞 | 자동차 안에서 마지막 독백이 끝나고 별장에 도착할 때 |
| 별장 옆 창문 | 창문 너머 불 켜진 복도와 바닥에 떨어진 동생의 휴대전화 | 주인공이 창문을 살펴볼 때 |
| 별장 복도 | 불 켜진 1층 복도와 휴대전화. 기존 1층 맵 이미지에서 재사용할 수 있는 부분을 확인합니다. | 열린 현관으로 들어가 휴대전화를 줍는 장면 |
| 정전 이후 | 같은 구도의 어두운 복도, 닫힌 현관문 | 천둥과 함께 불이 꺼질 때. 문 닫힘과 잠금쇠 소리를 거쳐 복도 안쪽의 발소리로 이어집니다. |

- 배경은 기존 게임 화면인 **800 × 600** 비율에 맞춥니다. 휴대전화, 현관등 등 단서는 하단 대화창 밖에 배치합니다.
- 불이 켜진 복도와 정전 직후 복도는 같은 구도와 소품 위치를 사용합니다. 조명 차이로 정전을 알아볼 수 있게 합니다.
- 문자 내용과 대사는 이미지에 넣지 않고 게임에서 출력합니다. 문자 화면을 별도로 표현할 경우에도 글자는 같은 대화 출력 기능으로 표시합니다.
- 대화창 배경과 다음 입력 표시를 공용으로 제작합니다. 캐릭터 얼굴 이미지는 필요할 때 추가할 수 있도록 공간을 남깁니다.
- 새 이미지 파일의 위치는 `game/art/opening/`을 제안합니다.

## 별장 도착 후 탐색

1. 자동차 장면이 끝나면 별장 앞에서 WASD로 이동합니다.
2. 초인종과 옆 창문을 E로 조사합니다. 창문 너머로 동생의 휴대전화를 발견합니다.
3. 현관으로 돌아와 문을 열고 복도에 들어간 뒤, E로 휴대전화를 줍습니다.
4. 휴대전화를 줍는 동작으로 정전과 현관문 잠김 연출이 시작됩니다. 복도 안쪽의 발소리를 알리는 마지막 대화가 끝나면 조작을 돌려줍니다.

## 정전 전후 조명

- **정전 전:** 별장 외부와 불이 켜진 복도를 탐색할 때 플레이어가 바라보는 방향에 관계없이 현재 화면을 볼 수 있습니다. 전방 시야각과 거리에 따른 어둠 효과는 적용하지 않습니다.
- **정전 순간:** 동생의 휴대전화를 줍고 불이 꺼지는 연출에 맞춰 어둠 효과를 켭니다. 대화가 열려 있는 동안에는 조명 전환을 연출로 처리하고, 게임 세계는 일시 정지 상태를 유지합니다.
- **정전 후:** 대화가 끝나고 탐색을 재개하면 기존 90도 전방 시야와 거리·벽 가림 규칙을 적용합니다.

## 쯔꾸르식 대화창

- 장면 이미지 위에 화면 하단을 가로지르는 대화창을 띄웁니다. 어두운 배경과 밝은 글자로 읽기 쉽게 표시하고, 이름칸과 본문을 구분합니다.
- 동생의 문자, 주인공의 대사와 생각, 자동 안내 음성은 **동생 · 문자**, **주인공**, **주인공 · 생각**, **자동 안내 음성**으로 표시합니다. 천둥·문 닫힘·잠금쇠·발소리는 장면 연출로 처리합니다.
- 대본의 화자 블록 하나를 대화 한 항목으로 표시합니다. 글자 수가 길면 대화창 폭에 맞춰 자동으로 줄을 바꿉니다.
- 한글과 문장부호를 포함한 본문을 **한 글자씩** 표시합니다. 출력은 경과 시간을 기준으로 진행하며, 글자 간격은 읽기 속도를 보며 조정합니다.

| 현재 상태 | Space를 한 번 눌렀을 때 |
| --- | --- |
| 현재 대화 출력 중 | 현재 내용의 나머지를 즉시 표시합니다. |
| 현재 대화 출력 완료 | 다음 대화로 이동하고 첫 글자부터 출력합니다. 배경 전환이 지정된 항목이면 배경도 함께 바꿉니다. |
| 현재 장면의 마지막 대화 출력 완료 | 대화창을 닫고 장면에 맞춰 탐색을 시작하거나 재개합니다. |

자동 출력으로 문장이 끝난 경우에도 Space로 다음 대화에 넘어갑니다. 출력이 끝나면 대화창 오른쪽 아래에 진행 표시를 띄웁니다. 키를 누르고 있을 때 발생하는 반복 입력을 무시해, 한 번의 입력으로 현재 문장이 완성되면서 다음 문장까지 건너뛰는 일을 방지합니다.

## 대화 중 게임 일시 정지

대화창이 열려 있는 동안 게임 세계의 갱신을 멈춥니다. 플레이어 입력에 따른 이동과 조사, Watcher의 추적·배회, 캐릭터 애니메이션, 퍼즐 상태와 게임 내 타이머가 정지합니다. 화면을 그리는 처리와 대화의 글자 출력, Space 입력, 대본에 지정된 배경·효과음 전환은 계속 처리합니다.

대화창이 닫히면 멈췄던 상태에서 게임을 재개합니다. 대화에 걸린 시간은 Watcher 이동이나 타이머에 누적하지 않습니다.

## 게임 연결과 구현 순서

1. 대본을 UTF-8 데이터로 정리합니다. 대화 항목에 장면 ID, 화자, 대화 유형, 본문을 두고, 필요한 항목에 이미지나 효과음 전환 시점을 지정합니다.
2. 임시 배경으로 대화창과 한 글자씩 나오는 출력부터 구현합니다. Space로 현재 항목을 완성한 뒤 별도의 입력으로 다음 항목에 넘어가는지 확인합니다.
3. 장면 이미지와 효과를 연결합니다. 집에서 자동차, 별장 외부, 정전 직후까지 대본 순서대로 전환합니다.
4. 기존 화면 관리에 오프닝 화면을 추가합니다. 타이틀의 새 게임으로 진입하고, 자동차 장면 뒤에는 별장 외부 탐색을 시작합니다. 조사 이벤트가 대화를 열면 게임을 일시 정지하고, 대화가 닫히면 탐색을 재개합니다. 정전 장면 이후에는 기존 1층 플레이로 이어집니다. 이어하기는 저장된 위치를 복원하고, 퍼즐 다시 시작은 곧바로 퍼즐을 초기화하는 흐름을 제안합니다.

## 완료 기준

- 새 게임에서 대본의 첫 문자부터 마지막 발소리까지 순서대로 진행합니다.
- 한글 대사가 한 글자씩 출력되고 긴 대사도 대화창을 벗어나지 않습니다.
- 출력 중 Space 한 번은 현재 대화만 완성합니다. 다음 Space 입력이 있어야 다음 대화나 플레이 화면으로 넘어갑니다. 키를 길게 눌러도 여러 대사가 건너뛰어지지 않습니다.
- 대화와 배경 전환이 맞고, 정전 전후의 차이와 창문 너머 휴대전화가 화면에서 구분됩니다.
- 별장 도착 직후 직접 이동하고, 초인종과 창문을 조사한 뒤 복도에서 휴대전화를 주울 수 있습니다.
- 대화 도중 기다려도 플레이어와 Watcher의 위치, 애니메이션 프레임, 퍼즐 상태 및 게임 내 타이머가 그대로 유지됩니다. 대사 출력과 Space 입력은 동작하며, 대화가 끝나면 시간이 건너뛰지 않고 게임이 재개됩니다.
- 마지막 대화가 끝나면 별장 1층에서 조작을 이어갈 수 있고, 기존 이어하기와 퍼즐 다시 시작 흐름을 확인합니다.
- 정전 전에는 방향을 바꿔도 화면이 어두워지지 않고, 정전 후에는 전방 시야와 벽 가림에 따라 밝은 영역이 바뀝니다.
