1주차 개발 명세서

생성할 이미지 목록

1. 저택의 1층
2. 인벤토리
3. 설정
4. 타이틀

개발 내용

1. 플레이어의 모든 키 구현
2. 게임 시작 화면
3. 저장 및 불러오기 지원
4. 마우스 및 인터페이스 간의 상호작용
5. 첫번째 간단한 퍼즐

상세사항

1. 1층에 거주하는 watcher는 총 3마리
2. 플레이어의 시야각은 90도 이며 플레이어 의 시야는 맵 끝까지 가는 것이 아닌 특정 길이에서 멈춘다
3. 플레이어가 보고있지 않는 시야각은 조금의 offset은 밝혀져 있지만 그렇지 않은 경우 밝혀져있지 않는다.
4. 밝혀져있지 않는 곳에 watcher가 있는 경우 watcher의 눈만 보일 정도로 어둡다
5. watcher는 어떤 상태이건 플레이어의 시야각에 들어올 시 멈춘다
6. watcher의 이동은 A* 알고리즘을 이용한다
7. 인벤토리 및 설정 시 게임은 일시 정지 상태가 되며 스프라이트 애니메이션은 계산하지 않는다



사용할 이미지

모든 이미지는 스프라이트임으로 애니메이션을 구현한다.

1. 플레이어가 idle 상태일 경우 protagonist_idle.png 을 사용한다
2. 플레이거가 move 상태일 경우 protagonist_v1.png 를 사용한다
3. watcher가 idle 상태인 경우 watcher-idle.png를 사용한다
4. watcher가 move상태인 경우 watcher-v1.png를 사용한다
