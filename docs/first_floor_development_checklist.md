# OUT OF SIGHT — 1층 및 첫 퍼즐 개발 목록

2026-11-17 · 「개발」, 「검토 역할 수행」, 「스토리 라인 작성」 협의

이 문서는 1층 개발과 첫 플레이 검증에 사용한다. 체크박스는 해당 항목의 완료 기준을 확인한 뒤 표시하고, 결정이 바뀌면 아래 변경 기록에 이유와 영향을 적는다.

## 기본 진행과 확인 결과

- 기본 동선은 정전 위치 → Watcher 첫 조우 → 서비스 복도 → 발판과 귀빈실 문 → 귀빈실 → 2층 계단이다.
- 식당과 주방은 공용 맵으로 돌아오는 선택 순환로이며, 욕실은 같은 문으로 나오는 선택 공간이다. 귀빈실에서 방문 기록부를 얻을 수 있고 2층 갤러리로 왕복할 수 있다.
- 「개발」 채팅의 코드 재현에서는 조작을 하지 않았을 때 초기 위치에 따라 약 2.36~3.08초 만에 Watcher가 접촉했다. 발판 중앙 근처(x=532)에서 Watcher를 멈춘 사례는 문을 통과했고, 문 쪽 가장자리(x=570)에서 멈춘 사례는 같은 입력으로 문이 닫혔다. 이 결과는 코드 재현이며 실제 조작감과 첫 플레이 이해도는 검증 대기다.

## 개발 목록

- [ ] **정전 직후 첫 조우의 반응 여유 확보.** 마지막 발소리에서 바로 이어간다. 시작점과 복도 모퉁이, Watcher 접근 경로를 조정해 돌아보고 다시 시선을 돌려볼 시간을 확보한다. 조우 시점은 유지하는 방향으로 검증한다.
- [ ] **관측 규칙을 행동으로 전달.** 접근하는 발소리, 전방 시야에 들어왔을 때의 정지, 시선을 돌렸을 때의 재개가 대응하게 한다. 처음 변화를 놓쳐도 다시 확인할 수 있어야 한다. 소리를 끈 상태에서도 움직임과 멈춤의 차이를 읽을 수 있는지 확인한다.
- [ ] **발판에서 문까지의 통과 여유 확인.** 발판 중앙 및 양쪽 가장자리에 Watcher를 멈춘 상태에서 출발 위치와 이동 경로를 바꿔 재현한다. 열린 문을 확인한 직후와 약 0.2초 뒤에 출발하는 경우를 초기 검증 조건으로 삼고, 정상 입력으로 통과할 수 있는 범위를 확인하고 발판·문·대기 위치의 배치를 우선 조정한다. 문턱에서 문이 닫힐 때 끼임과 재시도 가능 여부도 확인한다.
- [ ] **발판과 문의 관계를 환경 반응으로 전달.** 바닥에서 문틀까지 이어지는 금속 연결부, 발판이 내려가는 모습, 문 잠금쇠 소리, 문 표시 변화를 같은 작동에 연결한다. 플레이어가 직접 밟으라는 인상을 주는 발자국 표시는 피한다. 조사 문구는 장치가 연결됐다는 단서까지만 주는 방향으로 검증한다. 플레이어가 Watcher를 활용하는 방법을 떠올릴 수 있는지도 함께 확인한다.
- [ ] **선택 동선과 실패 복구 검증.** 식당·주방의 순환로, 욕실 왕복, 방 전환 직후의 시야와 충돌을 확인한다. 여러 Watcher가 활성화되거나 퍼즐에 쓰던 Watcher가 다른 방으로 넘어간 상황, 열린 문을 놓친 상황에서도 다시 유도할 수 있어야 한다. 새 게임에서 자동 저장 전에 실패한 경우의 복구 흐름도 확인한다.
- [ ] **귀빈실에서 2층 수색 동기 제공.** 귀빈실에서 위층 계단과 수색할 곳이 남았음을 알아볼 수 있도록 한다. 최소 단서 후보는 귀빈실 책상에 펼쳐진 방문 기록부의 최근 날짜와 ‘2층 갤러리’ 메모다. 동생과 직접 연결되는 흔적을 얼마나 드러낼지는 별도로 결정한다. 기록부 획득 여부와 관계없이 계단을 이용하는 현재 연결을 기준으로 한다.
- [ ] **첫 플레이 통합 검증.** 사전 설명 없이 새 게임부터 2층까지 진행하는 플레이를 관찰한다. 플레이어가 자신이 돌아봐서 Watcher가 멈췄다고 이해하는지, 발판과 문의 관계를 발견해 Watcher를 유도하는지, 실패해도 게임 안에서 다시 시도할 수 있는지 기록한다. 정답을 알려주기 전에 어디에서 멈췄고 어떤 단서를 근거로 움직였는지도 남긴다.

## 구현 및 검증 기록

| 항목 | 반영 결과 | 확인 범위 |
| --- | --- | --- |
| 첫 조우 | 휴대전화 위치와 공용 맵 Watcher 초기 배치를 조정했다. 정전 대사가 끝나면 해당 위치에서 조작을 시작한다. | 정지 입력에서 첫 접촉까지 4.84초. 북서쪽을 볼 때 정지하고 동쪽으로 시선을 돌릴 때 다시 움직이는 것을 재현했다. |
| 관측 단서 | 접근 중 발소리를 재생하고 거리에 따라 볼륨을 조절한다. 관측할 때는 발소리와 이동이 함께 멈춘다. | Pico2D에서 발소리 채널 시작과 정지를 확인했다. 소리를 끈 첫 플레이에서 알아차리는지는 검증 대기다. |
| 발판과 문 | 금속 띠, 눌림 표시, 잠금쇠 소리와 문 색을 실제 발판 상태에 연결했다. 조사 문구는 금속 띠의 연결을 묘사한다. | 문 앞 표시선에서 출발해 발판 중앙과 양 끝 근처, 세 높이, 네 가지 프레임 간격, 0초와 0.2초 대기를 조합한 72개 케이스에서 통과했다. 멀리서 출발해 문이 먼저 닫히면 복도로 물러날 수 있음을 확인했다. |
| 선택 동선과 복구 | 게임 오버 화면에 첫 퍼즐 다시 시도를 추가했다. 정전 이후 상태에서 다시 시도하고 기존 슬롯은 유지한다. | 식당·주방 순환, 욕실 왕복, 식당에서 공용 맵으로 돌아오는 활성 Watcher, 저장이 없는 상태의 재시도를 코드에서 확인했다. |
| 2층 단서 | 기존 귀빈실 계단과 2층 갤러리 안내를 유지한다. | 방문 기록부의 문구·날짜·작성자는 스토리 라인 작성 및 검토 역할 수행의 확인 대기다. |

체크박스의 완료 기준에 포함된 첫 플레이 이해도는 실제 플레이 관찰 후 표시한다.

## 결정이 필요한 항목

- 발판은 연결된 잠금장치의 반응부터 표현한다. 서빙 카트용 장치라는 유래는 후보로 남긴다. 채택하려면 현재 Watcher만 발판을 작동시키는 판정과 플레이어가 밟았을 때의 반응을 설명할 수 있어야 한다.
- 기록부에 적힐 날짜, 이름, 갤러리 표기의 의미와 작성자는 스토리 결정 사항이다. 동생의 행방을 이 구간에서 얼마나 드러낼지 함께 정한다.
- 정전 직후 체크포인트 도입 여부와 현재 저장 슬롯에 미치는 영향은 첫 실패와 복구 흐름을 플레이해 본 뒤 결정한다.
- 문 개방 지연과 잠금 유지 규칙은 배치 검증 결과를 보고 검토한다.
