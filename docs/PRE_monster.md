

====================================================

WATCHER


**첫 조우는 플레이어가 Watcher의 초기 배치 방에 처음 들어서는 순간**으로 정해요. 방에 들어가면 그 방에 처음 배치된 Watcher가 활성화됩니다. 활성화된 Watcher도 플레이어에게 관측되는 동안에는 멈춥니다. 주석 1

**배회는 방마다 정해 둔 지점을 A*로 오가는 방식**을 추천해요. 추적 거리 밖으로 벗어나면 현재 방의 배회 지점으로 이동하고, 도착하면 잠시 멈춘 뒤 다음 지점을 고릅니다. 다른 방으로 이동할 때는 통과할 수 있는 출입구를 이용하고, 플레이어가 아직 방문하지 않은 방도 목적지가 될 수 있습니다. 배회 중 플레이어가 추적 거리 안으로 들어오면 추적으로 전환하고, 관측되면 즉시 멈춥니다. 주석 2

| 항목                       | 설정                                                                                                                                                                                                             |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **초기 배치**        | 저택 1층의 방에 배치합니다. 기존 1주차 명세의 기준은**총 3마리**이며, 방별 배치 수는 아직 정하지 않았습니다.                                                                                               |
| **활성화**           | 각 Watcher는 플레이어가**그 개체와 처음 조우할 때**활성화됩니다. 조우 전에는 초기 위치에서 움직이지 않습니다.                                                                                              |
| **방 사이 이동**     | 활성화된 Watcher는 통과할 수 있는 출입구를 통해 다른 방으로 이동합니다.**플레이어가 아직 방문하지 않은 방**에도 들어갈 수 있습니다. 그 방에 원래 있던 Watcher는 자기 첫 조우까지 비활성 상태를 유지합니다. |
| **관측 중**          | 플레이어에게 관측되면 추적이나 배회 중에도 즉시 멈춥니다. 이동과 함께 스프라이트 애니메이션도 정지합니다.                                                                                                        |
| **관측되지 않을 때** | 활성화된 Watcher는 플레이어가 추적 거리 안에 있으면 **A***로 경로를 찾아 따라옵니다. 플레이어가 일정 거리 이상 멀어지면 추적을 멈추고 스스로 배회합니다.                                                   |
| **시야와 외형**      | 플레이어의 전방 시야각은**90도**이고 최대 시야 거리가 있습니다. 시야 밖 일부는 약하게 밝히고, 어두운 구역의 Watcher는**눈만**보입니다.                                                               |
| **스프라이트**       | 대기는`watcher-idle-v1.png`, 이동은`watcher-v1.png`를 사용합니다. 인벤토리나 설정을 열어 게임이 일시 정지되면 애니메이션 갱신도 멈춥니다.                                                                    |
| **첫 퍼즐**          | Watcher를 압력 발판 위로 유도해 귀빈실 문을 엽니다. 기존 프로토타입에서는 발판 위의 마지막 Watcher가 벗어나면 문이 닫힙니다.                                                                                     |
