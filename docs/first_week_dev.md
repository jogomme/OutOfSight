# OUT OF SIGHT 1주차 개발 명세서

저택 1층을 탐색하며 Watcher를 이용한 첫 번째 퍼즐을 해결할 수 있는 프로토타입을 만듭니다. 타이틀에서 게임을 시작하고, 플레이를 저장한 뒤 불러올 수 있도록 합니다.

## 이미지 제작

| 이미지 | 용도 |
| --- | --- |
| 저택 1층 | 플레이어가 이동하는 2D 쯔꾸르 스타일의 실내 맵 |
| 인벤토리 | 소지품을 확인하는 화면 |
| 설정 | 게임 설정을 표시하는 화면 |
| 타이틀 | 게임 실행 후 처음 표시되는 화면 |

저택의 공간 구성과 탐색 동선은 [1층 배치 제안](first_floor_layout_proposal.md)을 참고합니다.

## 개발 항목

| 항목 | 1주차 작업 |
| --- | --- |
| 플레이어 조작 | README에 명시된 이동, 제자리 방향 전환, 상호작용, 손전등 전환, 인벤토리, 일시 정지 입력을 구현합니다. |
| 게임 시작 화면 | 타이틀 화면에서 새 게임을 시작할 수 있도록 합니다. |
| 저장 및 불러오기 | 진행 상태를 저장하고, 저장한 상태에서 플레이를 이어갈 수 있도록 합니다. |
| 마우스와 인터페이스 | 마우스로 인터페이스의 버튼과 메뉴 항목을 선택할 수 있도록 합니다. |
| 첫 번째 퍼즐 | Watcher를 압력 발판으로 유도해 문을 여는 퍼즐을 구현합니다. |

## 시야와 조명

- 플레이어의 전방 시야각은 총 **90도**입니다. 시야는 최대 거리에서 끝납니다. 최대 거리의 구체적인 값은 퍼즐을 검증하면서 정합니다.
- 전방 시야 밖에는 일부만 약하게 밝히는 여유 영역을 둡니다. 그 밖은 어둡게 표시하며, 어두운 곳에 있는 Watcher는 눈만 보입니다.
- 약하게 밝히는 영역의 폭과 벽에 의한 시야 차단은 검증할 항목입니다.

## 저택 1층의 Watcher

- 1층에 Watcher를 총 **3마리** 배치합니다.
- Watcher는 현재 상태와 관계없이 플레이어의 전방 시야에 들어오면 이동과 애니메이션을 멈춥니다.
- 관측되지 않는 동안에는 **A\***로 이동 경로를 탐색합니다.

## 완료 기준

- 타이틀 화면에서 새 게임을 시작하고, README에 명시된 모든 조작을 사용할 수 있습니다.
- 마우스로 인터페이스 항목을 선택하고, 저장한 진행 상태를 불러와 이어서 플레이할 수 있습니다.
- 1층에 Watcher가 총 3마리 배치되며, 압력 발판 퍼즐을 해결해 문을 열 수 있습니다.
- 저택 1층, 인벤토리, 설정, 타이틀에 사용할 이미지 4종을 준비합니다.

- 90도 전방 시야와 제한된 시야 거리를 적용하고, 어둠 속 Watcher는 눈만 표시합니다.
- Watcher가 시야에 들어오면 멈추며, 관측되지 않을 때는 A* 경로로 이동합니다. 이 동작으로 발판 퍼즐을 풀고 귀빈실에 진입할 수 있는지 확인합니다.
- 두 캐릭터의 대기·이동 애니메이션을 확인하고, 인벤토리와 설정 화면에서 게임과 애니메이션이 일시 정지되는지 검증합니다.


## 첫 번째 퍼즐 상세

현관에서 접객 홀과 서비스 복도로 걸어서 이동합니다. 연회 식당, 준비 주방, 공용 욕실, 귀빈실은 출입문마다 별도 맵으로 전환합니다. 접객 홀에서 식당과 주방을 거쳐 서비스 복도로 돌아올 수 있습니다.

1. 서비스 복도의 동쪽 귀빈실 문을 E로 조사하면 압력 발판에 대한 단서를 얻습니다. 발판은 문 서쪽에 있고, Watcher 3마리 중 1마리는 발판 서쪽에서 시작합니다.
2. 발판의 동쪽으로 이동해 동쪽을 바라봅니다. 뒤쪽의 Watcher가 전방 시야에서 벗어나면 A*로 접근합니다. 벽이 있으면 통행 가능한 격자 경로를 찾아 우회합니다.
3. Watcher가 발판 안으로 들어오면 발판과 문 표시가 녹색으로 바뀝니다. Space+WASD로 Watcher를 바라보면 그 자리에서 멈춥니다.
4. 발판 중앙 부근에 정지시킨 뒤 동쪽 문으로 이동합니다. 움직이는 동안 관측이 끊겨도 Watcher가 발판을 벗어나기 전에 문턱에 닿으면 귀빈실로 들어갑니다. 마지막 Watcher가 발판을 벗어나면 문이 닫힙니다.
5. 귀빈실의 방문 기록부를 E로 조사해 인벤토리에 넣을 수 있습니다. 서쪽 문으로 나가면 서비스 복도의 귀빈실 문 앞으로 돌아옵니다.

전방 관측은 90도, 거리 430px이며 벽에 가립니다. 근거리 90px와 전방 바깥쪽 일부는 약하게 밝힙니다. 어두운 곳의 Watcher는 눈만 표시합니다. F는 전방 조명 밝기를 전환하며 관측 판정은 전방 시야를 따릅니다. Watcher 이동 속도 55px/s, 추적 정지 간격 28px, 발판 72×84px는 초기 검증 값입니다.

## 실행과 확인

프로젝트 루트에서 `python game/main.py`로 실행합니다. 타이틀과 메뉴 버튼은 마우스로 선택합니다. Esc 메뉴에서 저장하며, 타이틀의 Continue 또는 메뉴의 Load Game으로 이어서 플레이합니다. 저장에는 현재 방, 플레이어와 Watcher 위치·방향·애니메이션 상태, 퍼즐 진행, 인벤토리와 손전등 상태를 포함합니다.

`game/art`에 1층과 각 방의 맵 이미지 및 타이틀·인벤토리·설정 이미지를 둡니다. 타이틀은 비 오는 밤의 외딴 별장, 인벤토리는 랜턴과 배낭, 설정은 낡은 스위치를 이미지 소재로 사용했습니다. 캐릭터는 기존 4방향 대기·이동 시트를 재생하며 인벤토리·설정에서는 게임과 애니메이션을 정지합니다.
