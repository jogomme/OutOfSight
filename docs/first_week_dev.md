# OUT OF SIGHT 1주차 개발 명세서

저택 1층을 탐색하며 Watcher를 이용한 첫 번째 퍼즐을 해결할 수 있는 프로토타입을 만듭니다. 타이틀에서 게임을 시작하고, 플레이를 저장한 뒤 불러올 수 있도록 합니다.

## 이미지 제작

| 이미지 | 용도 |
| --- | --- |
| 저택 1층 | 플레이어가 이동하는 2D 쯔꾸르 스타일의 실내 맵 |
| 인벤토리 | 소지품을 확인하는 화면 |
| 설정 | 게임 설정을 표시하는 화면 |
| 타이틀 | 게임 실행 후 처음 표시되는 화면 |

저택의 공간 구성과 탐색 동선은 [1층 배치 제안](first_floor_layout_proposal.md)을 참고합니다.

| 항목 | 1주차 작업 |
| --- | --- |

| 마우스와 인터페이스 | 마우스로 인터페이스의 버튼과 메뉴 항목을 선택할 수 있도록 합니다. |
| 첫 번째 퍼즐 | Watcher를 압력 발판으로 유도해 문을 여는 퍼즐을 구현합니다. |

## 저택 1층의 Watcher

1층에 배치하는 Watcher는 총 **3마리**입니다. 첫 퍼즐은 플레이어가 Watcher를 바라보면 멈추고, 시야에서 벗어나면 다시 움직이는 기본 규칙을 활용합니다. 각 개체의 시작 위치와 동선은 1층 배치와 퍼즐을 함께 검증하면서 정합니다.

## 완료 기준

- 타이틀 화면에서 새 게임을 시작하고, README에 명시된 모든 조작을 사용할 수 있습니다.
- 마우스로 인터페이스 항목을 선택하고, 저장한 진행 상태를 불러와 이어서 플레이할 수 있습니다.
- 1층에 Watcher가 총 3마리 배치되며, 압력 발판 퍼즐을 해결해 문을 열 수 있습니다.
- 저택 1층, 인벤토리, 설정, 타이틀에 사용할 이미지 4종을 준비합니다.

## 첫 번째 퍼즐 상세

- 목표는 서비스 복도에서 Watcher를 압력 발판 위로 유도하고 동쪽의 귀빈실 문을 통과하는 것입니다. 귀빈실 안에서는 별도 맵으로 전환하며, 서쪽 문으로 나오면 복도 문 앞에 도착합니다.
- 복도 중앙에 발판과 잠긴 문을 배치합니다. 1층의 Watcher 3마리 중 1마리는 발판 서쪽에 두고, 나머지 2마리는 서쪽 통로에 임시 배치합니다.
- Watcher는 전방 시야에서 관측되면 멈춥니다. 관측이 끊기고 플레이어까지 벽에 가리지 않는 직선 경로가 있으면 플레이어 쪽으로 움직입니다. 프로토타입에서는 플레이어와 28px 간격을 유지합니다.
- 발판 영역 안에 Watcher의 중심이 들어오면 문이 열립니다. 발판 위의 마지막 Watcher가 벗어나면 문이 닫힙니다. 문까지 달리는 동안 Watcher가 발판을 벗어나기 전에 문턱에 도달해야 합니다.
- 검증 경로는 시작점에서 위로 복도에 진입한 뒤 동쪽으로 이동하는 순서입니다. 문에서 조금 떨어진 곳에서 동쪽을 바라보고 기다리면 뒤따라오는 Watcher가 발판에 올라옵니다. Space+WASD로 왼쪽을 바라봐 Watcher가 정지하는 것을 확인하고, 발판 중앙에 들어왔을 때 동쪽 문으로 이동합니다. 실패하면 R로 초기화합니다.
- 시야각 80도, 관측 거리 430px, Watcher 이동 속도 55px/s, 발판 72×84px는 퍼즐 검증용 임시 값입니다. 캐릭터와 벽은 충돌 확인용 도형으로 표시합니다.

프로젝트 루트에서 `python game/main.py`로 실행합니다. 이번 구현은 이동, 제자리 방향 전환, 일시 정지, 첫 퍼즐과 귀빈실 진입·복귀를 검증하는 단계입니다. 타이틀, 저장 및 불러오기, 마우스 UI, 상호작용·손전등·인벤토리 입력, 나머지 방, 아트 적용은 1주차 후속 작업입니다.
