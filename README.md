# OUT OF SIGHT

> **보고 있으면 안전하지만, 보지 않으면 길이 열린다.**

OUT OF SIGHT는 몬스터를 관측하여 행동을 제어하고, 그 몬스터들을 이용해 퍼즐을 해결하는 **2D 공포 퍼즐 게임**입니다.

## 게임 소개

몬스터는 기본적으로 어둠 속에 숨어 화면에 보이지 않습니다.

플레이어의 시야에 관측된 몬스터는 움직임을 멈춥니다. 플레이어는 이 특성을 활용하여 몬스터를 특정 위치로 유도하고, 다양한 퍼즐을 해결해야 합니다.

기존 공포 게임이 몬스터를 피하는 데 집중한다면, OUT OF SIGHT는 **몬스터를 의도적으로 마주하고 활용해야 한다는 점**에서 차별화됩니다.

퍼즐을 해결하며 게임을 진행할수록 새로운 종류의 몬스터가 등장하고 관측할 수 있게 됩니다.

## 핵심 시스템

### 1. 관측 시스템
- 몬스터는 기본적으로 어둠 속에 숨어 있습니다.
- 플레이어의 전방 시야에 관측된 몬스터는 정지합니다.
- 관측되지 않는 몬스터는 다시 움직일 수 있습니다.

### 2. 몬스터를 활용한 퍼즐
- 몬스터의 행동을 이용하여 주변 환경과 상호작용합니다.
- 몬스터를 압력 발판 위에 유도하여 문을 여는 등의 퍼즐을 해결합니다.
- 게임 진행에 따라 서로 다른 특성을 가진 몬스터가 등장합니다.

### 3. 공포 및 탐색
- 어두운 별장 내부를 탐색합니다.
- 손전등과 시야를 이용하여 주변을 확인합니다.
- 퍼즐을 해결하면서 탈출을 목표로 진행합니다.

## 조작 방법

| 키 | 기능 |
|---|---|
| W / A / S / D | 이동 |
| Space + WASD | 제자리 방향 전환 |
| E | 상호작용 |
| F | 손전등 ON/OFF |
| Tab | 소지품과 조사 기록 |
| Esc | 일시 정지 |

## 개발 환경

- **언어:** Python
- **게임 라이브러리:** Pico2D
- **게임 형식:** 2D 공포 퍼즐
- **개발 상태:** 1층 Watcher 퍼즐 프로토타입

## 개발 계획

| 단계 | 개발 내용 |
|---|---|
| 1 | 플레이어 이동, 맵, 벽 충돌 |
| 2 | 전방 시야와 관측 시스템, Watcher |
| 3 | 압력 발판과 문을 활용한 첫 퍼즐 |
| 4 | 손전등, Shade, Breaker 및 특수 퍼즐 |
| 5 | 스테이지 연결, 공포 연출, 탈출 조건 |
| 6 | 테스트, 그래픽 및 UI 개선, 발표 준비 |

**우선 개발 목표:** 3단계까지 구현하여 핵심 게임 플레이를 검증할 수 있는 프로토타입을 완성합니다.

## 프로젝트 안내

현재 프로젝트는 1층 Watcher 퍼즐 프로토타입 단계입니다.

README에 작성된 게임 시스템과 기능은 개발 목표이며, 실제 구현 상황에 따라 변경될 수 있습니다.

## 실행 방법

Python 3.10 이상에서 프로젝트 폴더를 열고 실행합니다.

```powershell
python -m pip install -r requirements.txt
python game/main.py
```

타이틀에서 **새 게임**을 누르고 저장 슬롯을 고르면 집과 자동차 장면을 거쳐 별장 앞에 도착합니다. Space로 대사를 완성하고, 한 번 더 누르면 다음 대사로 넘어갑니다. 별장 앞부터 WASD 이동과 E 조사로 진행합니다. 플레이 60초마다 현재 슬롯에 자동 저장합니다. Esc 메뉴에서도 진행을 저장할 수 있고 **이어하기**로 이어서 플레이합니다. E로 문과 발판을 조사하고 Tab → 조사 기록에서 발견한 내용을 다시 읽을 수 있습니다. 기록도 저장 슬롯에서 복원합니다.

정전 이후 1층에서 잠긴 문과 주변 물건을 E로 조사할 수 있습니다. 자유롭게 탐색하다가 연회 식당의 옷장을 열면 첫 Watcher 조우가 시작됩니다. 서비스 복도의 발판은 사람과 Watcher가 밟을 때 모두 작동합니다. 별도로 단서를 조사해 열 수 있는 선택 공간이 있습니다. 귀빈실 안의 계단은 2층 갤러리로 이어지며, 갤러리 계단으로 귀빈실에 돌아올 수 있습니다. 퍼즐의 세부 배치와 관측 수치는 초기 플레이 검증용입니다.

## 폴더 구조

- `game/main.py`는 실행 진입점이며, `game/framework.py`는 게임 루프를 실행합니다.
- `game/first_puzzle.py`와 `game/navigation.py`는 퍼즐 상태와 Watcher 경로 탐색을 처리합니다.
- `game/view.py`와 `game/art/`는 맵, 조명, 스프라이트와 메뉴 화면을 그립니다.
- `game/saves/`는 게임을 저장하면 생성됩니다.
- `assets/sprites/`에는 캐릭터 시트가, `docs/`에는 개발 명세와 발표 자료가 있습니다.
